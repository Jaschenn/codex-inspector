# CodexInspector.app

原生 SwiftUI + Rust 应用，支持 macOS 13 及以上版本。

## 检查窗口

左侧选择聊天或进程，右侧查看概览、配置层、AGENTS.md、Skills、MCP、合并配置与诊断。
聊天默认跟随最新轮次，也可固定查看历史轮次。支持聊天、项目和内容搜索。

## 活动统计

菜单栏展示当前对话累计 Token、输入/输出、缓存命中率及最新轮次耗时分布。
「查看详情」打开对应聊天的最新轮次。也可从 `Window → 活动统计` 打开独立摘要窗口。

可自动关联最近聊天，或手动选择进程和聊天。App Server 的自动关联依据为工作目录或 Codex Home，
不保证对应前台聊天。详情窗口的历史选择不会改变活动摘要。

## 文件与消息

配置层、AGENTS.md 和 Skills 支持浏览、编辑与创建文件；合并配置及会话指令只读。
编辑器支持语法高亮、行号、撤销重做、查找替换、自动缩进、换行及字体缩放。
保存前检查 JSON / JSONL / TOML 语法，检测外部修改，保留文件权限与符号链接。
当前支持不超过 2 MB 的 UTF-8 文本。

消息预览支持 Markdown 标题、列表、引用、表格、链接及高亮代码块。

| 快捷键 | 操作 |
| --- | --- |
| `⌘O` | 打开文件 |
| `⌘R` | 刷新检查 |
| `⌘S` | 保存编辑 |
| `⌘F` | 查找 |

## 用量与耗时

缓存命中率 = 缓存命中 Token ÷ 输入 Token。缓存属于输入，推理属于输出，不重复加入总量。
用量缺失时不当作零；进行中的调用可能尚未回报用量。耗时线仅覆盖日志记录区间，重叠部分只计一次。
悬停时间线或「未分类时间」可查看耗时及含义。

时间线区分日志明确记录的活动区间与「响应间隔（原因未知）」；后者仅由用户消息、工具返回或前一模型输出到下一模型事件的端点界定，不能当作内部推理或网络耗时。上下文压缩和 `clock.sleep` 主动等待单独统计。起止时间相同的记录优先使用明确报告的耗时，否则保留为时间点，不推算持续时长；统计限制中可查看这类记录及未识别活动类型。

Skill 使用 `o200k_base` 估算 `SKILL.md` 全文，包含 frontmatter，不包含引用文件；不代表该 Skill 已进入模型请求。
历史轮次用于检查当前磁盘内容，不还原历史配置或完整 LLM 请求。

可读取的磁盘配置按系统、用户、profile、受信任项目（根目录到当前目录）、CLI 覆盖的顺序合并。`-c` 和 `--config` 都是 TOML 键值覆盖，支持引号键、含空格的值及常用专用参数；项目层中 Codex 不允许覆盖的供应商、通知和遥测字段会被忽略并提示。未读取的云端默认值和组织强制策略不由这份磁盘重建结果证明。

指令发现跳过空文件，每个目录优先检查 `AGENTS.override.md`、`AGENTS.md`，项目目录再检查 `project_doc_fallback_filenames`。按 `project_doc_max_bytes` 限制纳入的字节数，保持 UTF-8 字符完整；发生截断时显示提示。文件编辑仍展示完整原文，发现结果不代表某次请求实际加载了这些文件。

「本轮活动」独立展示文件与工具概览，支持点击数量筛选、按路径搜索，以及文件活动／工具调用／执行记录切换。同一文件合并多种操作，默认显示文件名与项目内目录，展开后可查看完整路径、复制路径、在 Finder 定位及识别依据。长列表分批显示，工具按次数排序，执行记录按时间倒序。

模型调用与编排工具展开的执行操作分别计数，不重复相加。数据来自会话 JSONL，不依赖 `logs_2.sqlite` 或开启 OTel；通过操作 ID 合并开始和完成记录。文件变更保留完成／失败状态，读取和搜索仅表示可识别的目标，无法完整审计脚本、子进程、通配符或远端工具的文件访问；未识别命令数量单独提示。路径按当时工作目录解析，Finder 查看的是当前磁盘。
