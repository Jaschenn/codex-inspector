# Codex Inspector 0.3.0

概览滚动不再反复创建卡片，实时刷新避免在滚动手势中改变布局。活动路径只准备一次，报告比较移到后台；更新时间和菜单栏状态独立更新，减少无关的重排。

本轮活动展示读取、搜索和文件变更目标，以及模型调用、实际执行操作和次数。支持按类型筛选、路径搜索、展开证据和分批加载。时间线单独展示上下文压缩、主动等待与响应间隔，缺少证据的时间保持未知。

修复轮次菜单被刷新打断、旧时间线悬停提示残留、异常耗时整数转换和诊断日志写入失败问题。文件保存的外部修改检测、权限及符号链接保留通过回归。

验证：44 项 Rust、47 项 Swift 测试通过（其中 3 项性能基准默认跳过）；Rust 格式、Clippy 与 Swift 测试均通过。Apple Silicon 发布包启动、轮次切换、实时刷新、搜索和滚动已实测。最终实时滚动采样最长帧卡顿 16.67 ms、潜在延迟 63.52 ms；属于有限场景结果，不保证所有设备零丢帧。[完整性能报告](performance/2026-10-21-stability/RESULTS.md)。

发布：GitHub Actions 分别构建 arm64 与 x86_64 安装包并创建 GitHub Release，Release 成功后自动更新 `Jaschenn/homebrew-tap` 中的 Cask。Intel 构建由 CI 验证，实际运行仍需对应设备确认。产物仍为 ad-hoc 签名且未公证，首次启动可能需要在系统设置中允许。
