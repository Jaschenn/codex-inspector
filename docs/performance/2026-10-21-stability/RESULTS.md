# 0.3.0 性能与稳定性验证

本次保留已有的原生时间线、编辑器可见区高亮、行号索引与 Rust 增量缓存，并优化活动清单及概览刷新。

## 改动与证据

- 活动目标在视图输入更新时分组、排序一次；每行不再重新生成整份清单。动作与失败计数预先计算，筛选与可见行列表每次绘制只准备一次。
- 统计与活动卡片按全部输入内容比较后复用；目录或嵌套证据变化仍触发更新。报告内容比较移到引擎队列，只有 generation timestamp 改变时不重新发布报告。
- 概览只有少量卡片，改用固定 VStack；其他长列表继续懒加载，减少滚动时卡片反复创建及高度估计失效。
- 菜单栏图标按进程数/错误状态复用；刷新时间拆到独立页脚观察对象，避免每秒时间变化刷新整个检查窗口。历史概览整体按内容复用。
- 自动刷新在 AppKit 滚动手势结束后恢复，手动刷新保持立即执行；在途自动读数遇到滚动时不发布新快照。滚动视图使用弱引用，已关闭窗口不会长期阻止刷新。
- 原生轮次选择器只有选项/选择变化才重建收起菜单，避免无关刷新干扰打开菜单。该修复已通过回归和真实界面验证，历史轮次选择与返回最新轮次均正常。
- 时间线内容变化清除旧悬停状态；异常大、非有限耗时不会触发整数转换崩溃。诊断日志改用可捕获失败的 FileHandle API，避免恢复引擎时因日志写入失败而退出。
- 修正遗留 Python 的类型检查问题与格式；发布 CI 在打包前运行 Rust 格式、Clippy、测试及 Swift Release 测试。
- 构建脚本在编译前取得输出目录，避免编译后再次调用 SwiftPM 与其他测试的编译选项发生交错。

Release 合成基准：1000 个路径、2000 条证据、20 次重复。同样 12 次清单访问，重复分组排序的中位数 **77.79 ms**，准备一次的中位数 **6.11 ms**，减少约 **92%**。这是清单准备计算的对比，不是显示帧率。原始结果见 `preparation.json`。

## 验证范围

- Apple M4，16 GiB，macOS 27.0.1，arm64 Release。
- 最终 46 项 Swift 测试全部通过，无跳过，包含显式执行的编辑器与概览基准；21 项 Rust、33 项 Python 测试通过。最终日志：`/tmp/codex-validated-swift.log`、`/tmp/codex-validated-rust.log`、`/tmp/codex-validated-python.log`。
- Swift 格式、Rust fmt/Clippy、Python Ruff/mypy、差异检查通过。
- 实际应用验证连续上下滚动、执行记录切换与加载更多、实时用量和活动刷新。最终 0.3.0 包已复核启动、上下滚动及路径搜索，搜索得到唯一匹配且实时刷新保持有效。
- 10.96 秒 Time Profiler 场景包含连续滚动，未报告超过 250 ms 的 potential hang。采样仍显示 SwiftUI 布局成本；这个短样本不能证明所有场景无卡顿。
- 最终包的 8 秒 Animation Hitches 采样在较长收尾后成功导出：130 条 hitch 记录、12 条 potential hang。含实时最新轮次更新和脚本连续滚动，存在采样和自动化开销，且没有匹配的旧版基线；但这些记录表明仍需继续排查，不能宣布滚动问题已经解决。汇总见 `hitches.json`。此前 10.96 秒 Time Profiler 的短样本不足以覆盖该问题。
- 原始 Instruments 文件可能包含进程环境，仅保留在临时目录，不纳入仓库或发布包。
- 相同已完成轮次的布局比较，卡顿记录从 481 条降至 47 条，卡顿时长合计从 4145.79 ms 降至 437.50 ms。但两个窗口的恢复尺寸/侧栏宽度不同，因此不是严格 A/B；新样本仍有长 potential hang，不能仅以条数证明稳定。汇总见 `layout-comparison.json`。随后进一步隔离了每秒更新时间，最终结果见下方。

## 最终结果（18:59）

- 自动刷新合并为每秒最多一次；手动刷新和轮次选择立即执行。
- 菜单栏状态独立观察，只有进程数或错误状态改变才发布。内容比较在后台计算呈现版本号，概览、统计与活动卡片在主线程只比较整数；历史列表变化不重建概览，目录和证据变化仍更新。
- 历史轮次 0–8 秒滚动窗口：23 条 hitch，最长 29.17 ms；一段 potential hang，52.91 ms。原始汇总 `clock-isolated.json`。
- 最终实时轮次 0–8 秒滚动窗口：7 条 hitch，最长 16.67 ms，累计 66.67 ms；两段 potential hang，34.28 / 63.52 ms，未复现秒级阻塞。`final-live-scroll.json` 保留窗口内与窗口外全部记录；9.17 秒开始的 1293 ms 辅助功能查询属于测试结束后的 UI 读取，不计入预先设定的滚动窗口。
- 均使用 Apple M4、Release 包、六次一页上下滚动；采样期间无后台编译或界面树/截图读取。早期候选包数据保留用于排查，不作为最终性能结论。现场日志持续变化，以上为有限场景验证，不能保证所有硬件/负载零丢帧。
